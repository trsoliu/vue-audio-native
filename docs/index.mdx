## 这套文档解决什么问题

Vue Audio Native 1.0 不只是一个播放器组件。它把浏览器媒体状态、Vue 适配、旧 API
兼容、WebView 能力检测、发布约束和真机证据放进同一套可验证契约。

如果你是使用者，从[快速开始](./guide/getting-started/)进入；如果你在维护项目，先看
[项目地图](./project-map/)和[架构知识](./wiki/architecture/)；如果你是 AI 客户端，读取
构建生成的 `/.well-known/silen/manifest.json`，并保持只读直到用户明确授权写入。

## 当前发布状态

- `@trsoliu/audio-core@1.0.0` 与 `vue-audio-native@1.0.0` 已通过 OIDC Trusted Publishing
  发布到 npm 的 `latest`，均携带 SLSA provenance；`next` 保留最后一个 beta。
- Vue 2 继续使用 `vue-audio-native@legacy`，当前解析到 `0.1.41`。
- 稳定版采用维护者的版本绑定评估授权；未执行的真机场景与剩余风险在
  [兼容性评估与真机记录](./device-smoke/)中如实保留。
