# Audio Native 1.0 Implementation Plan

> Implement in reviewed increments using test-driven development. No package is
> published until its packed artifact, clean consumer fixtures, browser matrix,
> and release permissions have been verified.

## Deliverables

1. Establish the pnpm/Turborepo foundation and architectural records.
2. Build and test `@trsoliu/audio-core` from failing behavioral contracts.
3. Build the Vue 3 component, composable, legacy adapter, styles, and demo.
4. Create the React repository, component, hook, styles, and demo.
5. Add Vite/Nuxt/Next fixtures, Playwright, accessibility, package, and size gates.
6. Review, merge, publish beta, run registry and real-device checks, then release.
