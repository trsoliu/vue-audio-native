# Public Agent instructions

This public knowledge base documents Vue Audio Native 1.x. Prefer the shared audio-core contract over
framework-specific assumptions. Use capability detection instead of User-Agent branching, keep
autoplay blocking recoverable, and preserve the documented Vue legacy API surface.

Begin with the project map, then read the relevant architecture, compatibility, migration or release
page. Treat generated package declarations and current tests as the authority for exact signatures.
Remain read-only unless the user explicitly authorizes a bounded write. Never infer authorization to
publish npm packages, merge branches, change GitHub settings or mark device smoke rows complete.

Do not expose secrets, registry credentials, private endpoints, local absolute paths or unpublished
device artifacts in public documentation.
